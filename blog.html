MAY 2026 COMPUTER VISION

Smart Gate System — Vehicle Detection Integration

The latest challenge at Msoka IoT Lab: building a gate that opens automatically for authorized vehicles. The system uses an array of IR break-beam sensors combined with simple pattern-matching logic running on an ESP32 to classify whether an approaching object is a vehicle or pedestrian.
